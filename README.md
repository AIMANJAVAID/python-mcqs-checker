# Python MCQs Checker

A beginner-friendly Python project that checks students' multiple-choice question (MCQ) answers against a predefined answer key.

## Features

- Compares student answers with the answer key.
- Calculates the student's result.
- Supports unanswered questions.
- Checks whether the number of student answers matches the number of questions.
- Handles input formatting such as extra spaces and letter casing.

## Technologies Used

- Python

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the Python file:

```bash
python "MCQS checker.py"
```
